## 2. 关键发现

### 2.1 TC8M.ATC8G7 是实际发放月份
- **ATC8G7 ≠ ATC931**: ATC931是工资所属月，ATC8G7是实际发放月
- 8月报税时，ATC8G7=202607的批次包含1月、2月、3月、7月的补发工资
- **这是理解"本期收入"包含多月补发的核心**

### 2.2 TC8M→TC93 关联方式 (关键Bug已修复)

#### ⚠️ TC8M是汇总表，不能直接JOIN

TC8M同一组 (ATB930, ATC931, ATC937) 按**发放人数**拆成多行（ATC8M1=人数）：
```
unit=37284 month=202607 seq=1  → 3行 (ATC8M1=6/14/85, 分别对应6人批、14人批、85人批)
```

**直接JOIN导致TC93个人记录被"人数批次数"膨胀**：
- TC93 某人 gz=5370 → JOIN后匹配3行 → SUM=5370×3=16110 ❌
- 这是精确匹配率仅37.7%的根因

#### 正确算法：IN子查询过滤

```sql
-- 用TC8M定位哪些(结算单元, 工资所属月, 当月批次)在目标发放月份
SELECT AAC002, AAC003,
       SUM(NVL(ATC93AA,0) - NVL(ATC936,0) - NVL(ATC93BD,0)) AS 本期收入
       -- 工资总额 - 补发3 - 大病险(个人)
FROM TC93
WHERE (ATB930, ATC931, ATC937) IN (
    SELECT DISTINCT ATB930, ATC931, ATC937 FROM TC8M WHERE ATC8G7 = 202607
)
GROUP BY AAC002, AAC003
```

#### 三种方案对比

| 方案 | 条件 | 精确匹配率 | 说明 |
|------|------|-----------|------|
| A (仅unit+month) | (ATB930, ATC931) | 72.8% | 会包含seq=2(奖金)等非正常工资 |
| B (unit+month+seq) | (ATB930, ATC931, ATC937) | 85.5% | TC8M的ATC937可能指向错误批次 |
| C (JOIN直接关联) | INNER JOIN ON 3键 | 37.7% | ATC8M1人数导致膨胀 ❌ |

**方案B最优 (85.5%)**，但仍有14.5%不匹配，原因是TC8M.ATC937有时指向seq=2(奖金/补发)，而Excel取的是seq=1(正常工资)。

#### 本期收入公式验证

加入公式 `工资总额 - 补发3 - 大病险(个人)` 后，精确匹配率提升至 **90.7%**（6644/7322人）。

## 4. 已解决问题

### 4.1 ✅ 收入匹配率提升 (37.7% → 90.7%)
**修复1**: TC8M是汇总表，ATC8M1是发放人数，同(unit+month+seq)拆成多人数批次行。
直接JOIN导致TC93个人记录被乘以批次数。改用IN子查询DISTINCT过滤解决。(37.7% → 85.5%)

**修复2**: 本期收入公式修正为 `工资总额 - 补发3 - 大病险(个人)`，精确匹配率提升至90.7%。

### 4.2 ✅ ATC937 JOIN条件
**发现**: JOIN必须包含ATC937，但TC8M.ATC937可能指向非正常工资批次(如奖金seq=2)。
最优方案是IN子查询含ATC937，精确匹配85.5%。

## 5. 待解决问题

### 5.1 剩余9.3%不匹配 (678人)
**根因分类**:
1. **TC8M月份不一致** — 占多数。TC8M记录的工资所属月和Excel实际报税月份不一致（如TC8M只有6月，但Excel用2月或7月）
2. **TC=2×Excel** — 136人，同一(unit,month,seq)在TC8M出现多次导致膨胀
3. **ATC8G7=202608的8月初发薪** — 4,734人只有202608批次无202607批次（如于海瑶）

**设计决策**: 系统建议 + 用户手动确认。系统根据TC8M自动推荐组合，用户逐人确认/修改。

### 5.2 3,558人仅在TC中 (不在Excel)
**分布**: 大部分收入=0 (可能是劳务人员或已离职)，295人有收入。
**已知**: 手动报税人员不在系统中。

### 5.3 累计收入额来源不明
**现象**: 刘寅明 Excel累计=63,121 vs TC93 1-7月=49,408 (差13,713)。
**线索**: Excel备注提到"丽水研学基地项目"，可能涉及跨单位累计。
