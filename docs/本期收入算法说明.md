# 本期收入与验证公式说明

> 基于 202607 全月 19,958 条正常记录逐条回归验证得出（2026-08-25 更新）

## 一、本期收入公式

### 1. 全数据库字段名称

```
本期收入 = ATC93AA − ATC936 − ATC93BD − ATC93BE + ATC93X3 − ATC93E
```

### 2. 全字段注释

```
本期收入 = 本次工资总额 − 本次免税 − 大病险（个人承担） − 补缴及退款保险差额（个人） + 个人交纳现金 − 个人欠款
```

### 3. 注释（字段名称）

```
本期收入 = 本次工资总额(ATC93AA)
         − 本次免税(ATC936)
         − 大病险个人(ATC93BD)
         − 补缴及退款保险差额个人(ATC93BE)
         + 个人交纳现金(ATC93X3)
         − 个人欠款(ATC93E)
```

**说明**：

- `ATC936`（本次免税）经数据库交叉验证 = 采暖费(ATC93W21) + 独生子女费(ATC93W4)，405条非零记录100%精确吻合
- `ATC93BE`（补缴及退款保险差额个人）为本次回归验证新发现字段：缺失时导致差值正好等于该字段值的失败记录（如高子彬差值608.50=ATC93BE）
- `ATC93X3`（个人交纳现金）2026-08-31 回归验证新发现字段：现金交纳的社保计入本期收入、同时对应五险一金列抵扣（如宋红玥应发0交纳现金608.5报税收入608.5）
- `ATC93E`（个人欠款）同样计入本期收入减项（如马静 -1825.5−(−2434)=608.5，与回盘一致）；因已含在收入中，验证公式左式不再单独扣减，代数上与原左式等价
- 所有字段 NULL 按 0 处理（对应 Oracle NVL 语义）

## 二、免税公式

### 1. 全数据库字段名称

```
免税 = ATC936 + ATC93BD
```

### 2. 全字段注释

```
免税 = 本次免税 + 大病险（个人承担）
```

### 3. 注释（字段名称）

```
免税 = 本次免税(ATC936) + 大病险个人(ATC93BD)
```

---

## 三、验证公式（左=右校验）

### 1. 全数据库字段名称

```
左 = 本期收入 − BAA001 − BAA003 − BAA002 − CAA002
     − ATC93AG − ATC93Y2
右 = ATC93C + ATC93Z2 + BAA300 + ATC93D − 免税
通过 = |左 − 右| < 0.01
```

### 2. 全字段注释

```
左 = 本期收入 − 当月养老个人缴 − 当月失业个人缴 − 当月医疗个人缴 − 个人公积金月缴存额
     − 个人其他调整 − 扣款-大病险
右 = 本次实发金额(合计) + 税后扣除工会会费 + 个人承担代理费 + 本次个人所得税 − 免税
通过 = |左 − 右| < 0.01
```

### 3. 注释（字段名称）

```
左 = 本期收入
     − 当月养老个人缴(BAA001)
     − 当月失业个人缴(BAA003)
     − 当月医疗个人缴(BAA002)
     − 个人公积金月缴存额(CAA002)
     − 个人其他调整(ATC93AG)
     − 扣款-大病险(ATC93Y2)
右 = 本次实发金额合计(ATC93C)
     + 税后扣除工会会费(ATC93Z2)
     + 个人承担代理费(BAA300)
     + 本次个人所得税(ATC93D)
     − 免税
通过 = |左 − 右| < 0.01
```
